Cómo queda la solución en AWS

How the solution runs on AWS

Todo el código Python viaja en una sola imagen Docker que corre como dos Lambdas: una recibe la API y otra migra los CSV. Los datos viven en PostgreSQL dentro de una red privada.

All the Python code ships in one Docker image that runs as two Lambdas: one serves the API and the other migrates the CSV files. Data lives in PostgreSQL inside a private network.

Evolución Big Data

Big Data evolution

La PoC ya sigue un patrón medallion ligero. Si el volumen crece, el lake se añade aguas abajo de PostgreSQL, sin reemplazarlo.

The PoC already follows a lightweight medallion pattern. If volume grows, the lake is added downstream of PostgreSQL, not in place of it.

CapaEn esta PoCA escala
Bronce · crudoCSV en S3 · raw y el JSON original de cada fila rechazada en rejected_recordsTablas Iceberg crudas en S3, solo de anexado, alimentadas por CDC o streams

Oro · negocioLos dos endpoints de análisis (SQL)Tablas o vistas Iceberg agregadas, servidas a BI
LayerIn this PoCAt scale
Bronze · rawCSV files in S3 · raw and the original JSON of every rejected row in rejected_recordsAppend-only raw Iceberg tables on S3, fed by CDC or streams
Silver · cleanValidated tables departments, jobs, hired_employeesConformed Iceberg tables; validation as Spark or Glue jobs with data-quality checks
Gold · businessThe two analytics endpoints (SQL)Aggregated Iceberg tables or views served to BI

Cuándo dar el paso

Decenas de millones de filas o más, varios sistemas de origen, muchos consumidores de BI consultando a la vez, o eventos que llegan de forma continua (Kinesis o MSK en lugar de lotes REST).

When to make the move

Tens of millions of rows or more, several source systems, many BI users querying at once, or events arriving continuously (Kinesis or MSK instead of REST batches).

Por qué no ahora

El reto es una carga transaccional pequeña que necesita llaves foráneas aplicadas, y pide priorizar la claridad sobre el sobrediseño. Snowflake no hace cumplir las llaves foráneas, así que la validación seguiría en la aplicación.

Why not now

The challenge is a small transactional workload that needs enforced foreign keys, and it asks to prioritise clarity over over-engineering. Snowflake does not enforce foreign keys, so validation would stay in the application.
